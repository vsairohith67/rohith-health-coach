# Security policy

Report vulnerabilities privately to the repository owner. Include version, affected component, safe reproduction steps, and impact; do not include personal health records, tokens, private URLs, FIT files, screenshots, or another person’s data.

Supported pre-GA version: `1.0.0-rc5` only. The owner will acknowledge, reproduce with synthetic data, classify severity, patch/add regression evidence, rotate credentials if needed, and publish a private advisory/release. Do not open a public issue for an exploitable health-data/security defect.

Operational incidents follow `INCIDENT_RESPONSE.md`; AI/MCP incidents also follow `docs/INCIDENT_RESPONSE_AI.md`.
