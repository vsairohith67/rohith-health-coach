# Hugging Face optional integration

The connected account is personal/non-Pro and read-scoped. The model-search connector was unavailable at runtime, so official public model cards were reviewed through the web instead. No model, dataset, Space, endpoint, or Job was created, downloaded, uploaded, or billed.

Hugging Face Inference is an external processor and remains disabled. Enabling it requires an implemented provider, private token storage, explicit user consent, data minimization, retention/training/region review, fixed model/version, safety evaluation, cost cap, revocation, and confirmation that only aggregate envelopes leave the system. A local download is preferable when hardware permits.
