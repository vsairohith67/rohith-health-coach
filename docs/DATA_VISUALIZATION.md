# Data visualization

Charts communicate provenance and uncertainty, not just shape.

- Every chart names the metric, unit, date range, and local timezone.
- Gaps remain gaps; lines are not interpolated across missing days.
- Partial days use a distinct visual treatment and text label.
- Baseline bands appear only when a baseline exists and show maturity.
- Tooltips and adjacent text expose source, source timestamp, completeness, and quality flags.
- Colour is never the only status signal. Text and shape carry the same meaning.
- Comparisons avoid dual axes and causal wording.
- On narrow screens, summaries remain readable without horizontal scrolling; dense series may simplify but never hide missingness.

The Today sleep chart uses a readable line and evidence rail. Reduced-motion preferences suppress nonessential movement. Structured Ask cards use the same envelope semantics as the web dashboard and ChatGPT widget.
