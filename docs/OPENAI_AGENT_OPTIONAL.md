# OpenAI agent optional integration

No OpenAI API provider or autonomous agent is enabled. A future optional provider must use a server-side key, a fixed model/version where available, minimal aggregate envelope, schema-constrained output, low output cap, timeout, zero tool writes, no background autonomy, safety validation, and deterministic fallback.

The private ChatGPT app path is MCP-based and separate from an API narrative provider. Public app submission, external AI activation, and medical decision automation are prohibited in RC4.
