# Coaching rules

The deterministic coach is informational and conservative.

1. Check freshness, completeness, and baseline maturity before interpreting a metric.
2. Prefer multi-day patterns; describe one-day changes as observations.
3. Generate only findings backed by evidence IDs present in the same result.
4. Offer no more than three actions and identify one clear priority.
5. Use practical actions such as protecting a sleep window, taking a light walk, or checking source synchronization.
6. Never diagnose disease, infer a cause, predict an event, prescribe treatment, or recommend changing medication.
7. Never shame the user or use panic language.
8. Preserve uncertainty and device limitations.
9. If self-reported emergency language matches the fixed urgent pattern, stop normal coaching and show urgent-help guidance.

AI may rephrase these outputs only after schema, evidence, numeric-claim, medication, diagnosis, and markup checks pass. Otherwise the deterministic fallback is returned.
