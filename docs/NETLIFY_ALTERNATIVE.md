# Netlify alternative

Netlify is an alternative web host only. Do not deploy it simultaneously with Vercel. `netlify.toml` records the frozen Node/pnpm build shape, but no site existed in the connected Free team and no site was created.

If selected instead of Vercel, repeat all preview/production environment separation, Next.js runtime compatibility, private response caching, headers, logs, smoke, rollback, and cost checks. Disable/delete the Vercel production target before treating Netlify as authoritative.
