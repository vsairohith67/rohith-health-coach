# Private pilot checklist

- [ ] Dedicated private Supabase project/cost/region confirmed.
- [ ] Migrations, hosted Auth/RLS/Storage/advisors pass with two synthetic users and anonymous client.
- [ ] Ingestion token issue/use/duplicate/rate/revoke/rotate works with synthetic payloads.
- [ ] Preview/production web security, accessibility, PWA cache, logs, rollback, and monitoring pass.
- [ ] Private FIT worker and retention pass; official decoder decision recorded.
- [ ] iPhone Shortcut manual synthetic run, offline/retry/duplicate/revoke tests pass.
- [ ] Privacy notice, retention, backup lag, export/deletion, consent, and incident owner confirmed.
- [ ] All AI/MCP/ChatGPT/external providers remain disabled for first real-data pilot.
- [ ] First scope is one owner, one bounded day/source; no medication, notes, routes, or unrelated Health types.
- [ ] After import, verify provenance/missingness, export, deletion, object cleanup, and token revocation.

Any failed item stops real-data use.
