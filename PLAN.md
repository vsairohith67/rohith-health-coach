# Four-prompt release plan

The repository is delivered through four preserved release gates:

1. RC1 establishes the deterministic PWA, contracts, database/RLS, ingestion, analytics, coach, FIT boundary, documentation, and tests.
2. RC2 independently audits and repairs that baseline, adds traceability and adversarial evidence, and packages a clean candidate.
3. RC3 prepares connected infrastructure conservatively. Hosted or physical-device gates remain blocked unless executed against an unambiguous account with no paid change.
4. RC4 adds a bounded Health Query Service, provider-neutral AI gateway, local-first model adapter, read-only MCP, OAuth security primitives, Codex/ChatGPT packaging, widget, 200+ synthetic evaluations, and final archives.

All real-data, external-AI, public-MCP, and write-agent features are default-off. Deterministic analytics remain authoritative.
